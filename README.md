# 知境学苑 · Liminal Academy (AfterBell)

专为**大学课下研学与教师智能管控**打造的轻量级三端教育智能体网站——聚焦课下学习闭环，用 AI 替代教师的重复性批改、答疑、盯人与留痕工作，并以低门槛、透明化的碎片研学体验激发大学生主动学习。深度适配桌面端与手机端浏览器。

## 核心亮点

- **首页门户**：融合暖象牙宣纸、学术午夜蓝与香槟古金的杂志编辑风设计，支持三端一键切换与实时数据联动。
- **学生研学端（Mobile-First + 手机悬浮底部导航）**：
  - 平时表现透明进度环 & AI 推荐「今日最短提分路径」
  - 3 分钟碎片微闯关（即时解析 + 研学积分 + 六维知识图谱更新）
  - 24 小时 AI 苏格拉底私教（3 种风格人设，启发引导不给直接抄袭成品）
  - 作业即时 AI 初评 + **「10 秒防糊弄验真追问」**
  - 一键生成「个人 15 分钟考前急救包」、匿名「同问热力墙」与实用特权兑换铺
- **教师智控台（AI 减负核心）**：
  - 全班「知识点 × 学生」二维学情热力矩阵（手机端自动转为精简学情卡片）+ 单生全景档案与私密备注
  - AI 作业初审与模板抄袭拦截台，支持**一键批量放行全部正常项**
  - 共性同问聚类台，AI 拟定回复初稿后**一键群发所有同问同学**
  - 讲义要点一键生成 3 分钟微闯关并实时派发至学生端
  - 一键生成可复制/打印 PDF 的《班级学情达成度分析报告》《学困生精准帮扶台账》《平时分透明明细表》
- **运营配置端（自主可控）**：
  - 课程信息、入班邀请码、透明过程性权重滑块、助教分权与特权库存调控
  - AI 自动催办与防掉队引擎开关 + 自动巡检触达留痕日志
  - 支持零配置内置演示引擎，或直连 DeepSeek / 通义千问 / OpenAI 兼容真实大模型 API（密钥仅存本机浏览器）


```bash
npm run build
```

## 一键公网部署（手机可直接打开）

项目已适配相对路径（`base: './'`），支持零改造部署到以下任意免费平台：

### 方式一：GitHub Pages（最省事，仓库内置工作流）
1. 打开 GitHub 仓库 → **Settings** → **Pages**；
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**；
3. 等待约 1 分钟自动构建完成，即可通过公网地址访问：`https://mzsjlx.github.io/AfterBell/`。

### 方式二：Vercel / Cloudflare Pages（国内访问更稳定）
1. 登录 [Vercel](https://vercel.com) 或 [Cloudflare Pages](https://pages.cloudflare.com)；
2. 导入 GitHub 仓库 `mzsjlx/AfterBell`（构建命令 `npm run build`，输出目录 `dist`，已内置 `vercel.json`）；
3. 点击 Deploy 即可获得公网 HTTPS 链接，手机扫码或微信里点开即可直接使用。
